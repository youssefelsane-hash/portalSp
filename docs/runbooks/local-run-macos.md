# تشغيل المنصّة كاملة على ماك — من الصفر

> الملف ده هو **المرجع الوحيد** للتشغيل المحلي. كل الأوامر هنا اتنفذت فعلاً، مش مكتوبة من الذاكرة.

> **«الـAPI بيقلع وبعدين مايردش» ليه سببين مختلفين تمامًا** — الاتنين اتشافوا على نفس الجهاز
> بنفس العَرَض بالحرف. القسم ٠ سبب، والقسم ٢-ب سبب تاني. `dev-doctor.sh` بيفرّق بينهم بدليل:
>
> | | نسخة Node غير مدعومة | استنزاف pool القاعدة |
> |---|---|---|
> | نسخة Node | ≥ 25 | مدعومة (22) |
> | اللوحتين (:3001/:3002) | ماتوا كمان | شغّالين عادي |
> | اتصالات التطبيق على القاعدة | **صفر** | **واصلة لسقف الـpool** |
> | `pg_locks` أقفال استشارية | 0 | كانت **8 ممنوحة** (قبل إصلاح 0272) |
> | الإصلاح | Node 22 | موجود في الكود من migration 0272 — اعمل `git pull` |

## ٠) المتطلب اللي بيكسر كل حاجة لو غلط: نسخة Node

**المدعوم: Node 20.9 → 24. وCI بيستخدم 22.**

ده مش تفضيل — ده اللي اتقاس. على **Node 26** بالظبط:

| الجزء | اللي بيحصل |
|---|---|
| لوحة الإدارة + موقع العميل | `next dev` **مابيقلعش خالص** — مفيش نسخة native من SWC/turbopack للإصدار ده |
| الـAPI | بيقلع ويطبع `Nest application successfully started` وبعدين **مابيردش على أي طلب** (`/health` بيعمل timeout) |
| تطبيقات Flutter | بتشتغل عادي، بس مفيش API ترد عليها ⇒ لودينج لانهائي ومفيش OTP |

يعني الأعراض بتبان زي «البيانات مش موجودة» والقاعدة سليمة ١٠٠٪. النسخة المدعومة متسجّلة دلوقتي
في `engines` في كل `package.json` وفي `.nvmrc`، وبيتفحص في `scripts/mac-dev-up.sh`
و`scripts/dev-doctor.sh` — فالغلط ده مابيعدّيش صامت تاني.

```bash
node -v                     # لازم تطلع v20.x أو v22.x أو v24.x

# لو أحدث من كده:
brew install node@22
echo 'export PATH="/opt/homebrew/opt/node@22/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc && node -v

# الاعتماديات المبنية على النسخة القديمة لازم تتمسح — مش هتشتغل مع النسخة الجديدة
cd ~/portalSp
rm -rf node_modules apps/*/node_modules packages/*/node_modules
```

## ١) شغّل كل حاجة — أمر واحد

```bash
cd ~/portalSp
git checkout main && git pull origin main
./scripts/mac-dev-up.sh
```

بيعمل ٧ خطوات وبيتحقق من كل واحدة قبل ما يكمّل: Docker+Node ⇒ Postgres/Redis/MinIO ⇒ ملفات
البيئة ⇒ الاعتماديات + بناء `shared-types` ⇒ الـmigrations ⇒ فحص البيانات والصلاحيات ⇒
الخدمات التلاتة. في الآخر بيطبع **أرقام الحسابات الموجودة في قاعدتك أنت** (مش أرقام ثابتة).

**بياناتك مش بتتلمس**: الزرع بيشتغل **بس لو `service_zones` = صفر** — يعني قاعدة فاضية تمامًا.
لو عندك مناطق وأسعار وحسابات بنيتها بنفسك، السكريبت مابيضيفش ولا بيعدّل أي صف.

أوامر تانية:
```bash
./scripts/mac-dev-up.sh --stop       # قفل كل حاجة
./scripts/mac-dev-up.sh --reset-db   # مسح القاعدة وبناها من الأول (بيمسح بياناتك المحلية)
```

## ٢) لو حاجة مش ظاهرة — شغّل التشخيص قبل أي تخمين

```bash
./scripts/dev-doctor.sh
```

قراءة بحتة، بيفحص السلسلة كاملة بالترتيب: Node ⇒ كونتينرات ⇒ عدد الصفوف في القاعدة ⇒ الـAPI
(`/health` + الكتالوج + **طلب OTP حقيقي**) ⇒ اللوحتين مع آخر سطور اللوج ⇒ حسابات الصلاحية
الكاملة ⇒ الوصول من الشبكة للموبايل. الترتيب مقصود: أول ❌ من فوق هو السبب، واللي تحته نتيجة.

## ٢-ب) لو الـAPI قلع وبعد دقيقة وقف يرد (على نسخة Node مدعومة)

ده كان عطل حقيقي في الكود، **اتصلح** في migration 0272 + `sweep-lock.ts`. لو شفته على نسخة
قديمة من الكود، البصمة المميزة:

```bash
# ١٠ اتصالات، ٨ منهم آخر استعلام لكل واحد pg_try_advisory_lock:
docker exec baytak-db psql -U baytak -d baytak -c \
  "SELECT state, left(query,60), count(*) FROM pg_stat_activity WHERE datname=current_database() GROUP BY 1,2 ORDER BY 3 DESC;"
# و٨ أقفال استشارية ممنوحة:
docker exec baytak-db psql -U baytak -d baytak -c "SELECT count(*) FROM pg_locks WHERE locktype='advisory';"
```

**السبب**: الدورات المجدولة (١٦ منها بتولع في نفس الثانية عند الدقيقة الأولى) كانت بتاخد قفلًا
استشاريًا مربوطًا بالجلسة، فكل دورة شغّالة كانت بتحجز اتصال من الـpool طول عمرها — وجوّه الدورة
بتطلب اتصال تاني مش موجود. تفاصيل كاملة في [ADR-0076](../adr/0076-sweep-leases-not-session-locks.md).

**الإصلاح**: `git pull origin main` وبعدين `./scripts/mac-dev-up.sh` (بيطبّق 0272 تلقائيًا).
بعده `/health` بيرجّع أرقام الـpool جوّه الرد نفسه:

```bash
curl -s localhost:3000/api/v1/health
# {"status":"ok","database":"up","pool":{"total":3,"idle":1,"waiting":0,"max":10}, ...}
```

`waiting` فوق الصفر لفترة = ضغط حقيقي على الـpool (والـAPI بيسجّله في اللوج لوحده كمان).
وللاطمئنان إن الدورات شغّالة فعلاً:

```bash
docker exec baytak-db psql -U baytak -d baytak -c \
  "SELECT lock_name, holder_instance, renewed_at, run_count FROM sweep_leases ORDER BY renewed_at DESC LIMIT 10;"
```

## ٣) الدخول — كود الـOTP

مفيش SMS محليًا. الكود بيتطبع في لوج الـAPI:

```bash
tail -f .dev-logs/api.log | grep -i otp      # الكود هو آخر توكن بعد السهم ←
```

**لو اللوحة فتحت والسايدبار فيه بندين تلاتة بس**: الحساب داخل فعلاً، بس دوره مش شايل
الصلاحيات (بعد تدقيق S-1 بقى كل مسار أدمن محتاج صلاحية صريحة). ده بيبان زي «النظام مكسور»
وهو مسألة تصريح:

```bash
node scripts/admin-access.js                          # كل حسابات الأدمن وعدد صلاحياتها الفعلي
node scripts/admin-access.js --grant-super +2010…     # صلاحية كاملة لحساب موجود
```
بعدها **خروج ودخول تاني** — الصلاحيات بتتحمّل وقت الدخول.

## ٤) تطبيقات Flutter

```bash
export PATH="$PATH:/opt/flutter/bin"
```

### إيموليتور أندرويد
الإيموليتور بيشوف الماك على `10.0.2.2` والتطبيقات مظبوطة على ده تلقائيًا — مفيش إعداد.

```bash
cd apps/technician-app && flutter run --dart-define=ALLOW_EMULATOR=true
cd apps/customer-app   && flutter run
```

`ALLOW_EMULATOR` ضروري لتطبيق الفني بس: فيه فحص أمان بيرفض الإيموليتور (بيانات مالية).
التجاوز ده **مقفول على `kDebugMode`** — في أي build إنتاجي بيتجاهَل تمامًا، والروت/الجيلبريك
بيفضل مرفوض في كل الحالات.

### موبايل حقيقي بالكابل
لازم عنوان الماك على الشبكة (`localhost` عند الموبايل معناه الموبايل نفسه):

```bash
LAN=$(ipconfig getifaddr en0)          # لو فاضي جرّب en1
cd apps/technician-app && flutter run --dart-define=ALLOW_EMULATOR=true --dart-define=API_BASE_URL=http://$LAN:3000/api/v1
cd apps/customer-app   && flutter run  --dart-define=API_BASE_URL=http://$LAN:3000/api/v1
```

شروط: الموبايل والماك على **نفس الواي-فاي**، ووضع المطوّر + تصحيح USB مفعّلين
(`adb devices` لازم يشوف الجهاز). لو `dev-doctor` قال إن الـAPI مش مسموع على عنوان الماك،
السبب غالبًا جدار حماية macOS: الإعدادات ← الشبكة ← جدار الحماية.

## ٥) أعطال متكررة ومعناها الحقيقي

| العرض | السبب الفعلي | الإصلاح |
|---|---|---|
| اللوحتين مابيفتحوش + الـAPI بيطبع «started» وبعدين مايردش | نسخة Node أحدث من المدعوم | القسم ٠ |
| اللوحتين شغّالين والـAPI بيقف بعد دقيقة | استنزاف pool من الدورات المجدولة (اتصلح في 0272) | القسم ٢-ب |
| لوحة واحدة بس مش بتفتح على الماك | Turbopack مش شغّال في البيئة دي | `npm run dev:webpack` — والسكريبت بيعمله تلقائيًا |
| اللوحة فاتحة والسايدبار شبه فاضي | الحساب بلا صلاحيات (S-1) | `scripts/admin-access.js` |
| كروت رمادية بتحمّل للأبد | الـAPI مش بيرد أو بيرجّع 403 | `dev-doctor.sh` — أول ❌ من فوق |
| تطبيق العميل فاضي والفئات موجودة | مفيش مدينة/نطاق خدمة ⇒ مفيش عنوان ⇒ مفيش حجز | أضف نطاق من اللوحة، أو `seed-dev-data.js` على قاعدة فاضية |
| الموبايل بيقول «الخادم مش متصل» | التطبيق بيكلّم `localhost` = الموبايل نفسه | `--dart-define=API_BASE_URL=http://<عنوان-الماك>:3000/api/v1` |
| الواجهة شايفة سلوك قديم | عملية API قديمة على :3000 | `--stop` بيقفلها، والتشغيل بيقفلها تلقائيًا |
| قيمة جديدة من `shared-types` بتطلع `undefined` | `dist/` مش متبنية | `npm --prefix packages/shared-types run build` |
