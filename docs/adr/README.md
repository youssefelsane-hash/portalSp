# ADR — قرارات معمارية موثقة

كل قرار معماري كبير (اختيار تقنية، تغيير في الـ schema الجوهري، تغيير في الحدود بين الموديولات) يتكتب هنا كملف مرقّم قبل التنفيذ، مش بعده.

## اسم الملف
`NNNN-عنوان-مختصر.md` — مثال: `0001-modular-monolith-first.md`

## القالب

```markdown
# ADR-000N: العنوان

**الحالة:** مقترح | معتمد | مستبدَل بـ ADR-000X
**التاريخ:** YYYY-MM-DD

## السياق
ليه القرار ده لازم يتاخد دلوقتي؟

## القرار
إيه اللي هنعمله بالظبط.

## البدائل اللي اتقيّمت
- بديل 1 — ليه رُفض
- بديل 2 — ليه رُفض

## الأثر
إيه اللي هيتأثر (كود، فريق، تكلفة، وقت).
```

## أول ADR مقترح (مرجعه الماستر بلان §2.1)
- `0001-modular-monolith-first.md` — نبدأ Modular Monolith، ونفصل أول خدمة (Notifications) عند 50 ألف طلب/شهر أو فريق > 8 مطورين.
