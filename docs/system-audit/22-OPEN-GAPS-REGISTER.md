# 22 — سجل الفجوات المفتوحة (Open Gaps Register)

> **النتيجة اللي المستند ده موجود عشانها** (ملاحظة التوثيق في تدقيق النظام):
>
> فيه **٢٨٩ إشارة «فجوة موثّقة»** موزّعة على عشرات الـREADMEs. الأغلبية بتقول «كانت فجوة…
> اتقفلت»، لكن **مفيش سجل واحد بيفصل المفتوح عن المقفول** — فمعرفة «إيه اللي لسه ناقص» كانت
> محتاجة قراءة كل الملفات كاملة.
>
> ده **دَين توثيقي**: التوثيق الصادق اللي مش قابل للاستعلام بيتحوّل مع الوقت لضوضاء.

---

## 1. الحل: مولَّد، مش مكتوب بالإيد

```bash
node scripts/list-documented-gaps.js             # ملخّص + اللي محتاج نظرة
node scripts/list-documented-gaps.js --all       # كل الإشارات (مقفولة ومفتوحة)
node scripts/list-documented-gaps.js --markdown   # جدول جاهز للصق
```

**ليه سكريبت مش جدول مكتوب؟** جدول مكتوب بالإيد بيبوظ بعد أول سيشن — يتضاف فجوة جديدة في README
ومحدش يفتكر يحدّث الجدول، فيرجع نفس الدَين. السكريبت بيقرا **المصدر** كل مرة، فالسجل مايقدرش
ينحرف عن الواقع.

---

## 2. إزاي بيفرّق بين المفتوح والمقفول

التصنيف بيقرا **لغة التوثيق نفسها**، وأقوى إشارة فيه هي **زمن الفعل**:

| النمط | التصنيف | ليه |
|-------|---------|-----|
| «**كانت** فجوة موثّقة…» | ✅ مقفولة | الماضي في العربي هنا معناه «بقت مقفولة»، والجملة بعدها بتشرح الإصلاح |
| «فجوة موثّقة **صراحة**» (بلا «كانت») | 🔸 محتاجة نظرة | تسجيل لحاجة **لسه ناقصة** |
| نص مشطوب (`~~…~~`) | ✅ مقفولة | الفريق شطبه بنفسه بعد الإغلاق |
| «اتقفلت / اتصلحت / اتحلّت / خلصت» | ✅ مقفولة | علامة إغلاق صريحة |

> **التمييز ده لوحده** نقل ١٨١ نتيجة كاذبة لخانتها الصح — من «١٨١ فجوة مفتوحة» (رقم مرعب ومضلّل)
> لـ**١١٤ إشارة محتاجة نظرة**.

⚠️ **التصنيف مساعد مش حَكَم.** «🔸» معناها «اقرا السطر ده»، مش «دي فجوة مفتوحة مؤكّدة».

## 4. الفئات الغالبة في «المحتاج نظرة»

بعد قراءة العيّنة، الـ١١٤ بتقع في أربع فئات مختلفة تمامًا في الخطورة:

| الفئة | مثال | الخطورة الحقيقية |
|-------|------|-------------------|
| **شغل مخطّط في الرؤية** | بنود `docs/08` | 🟢 مش دَين — ده الـbacklog |
| **تحقق حي ناقص** | «مفيش اختبار بمتصفح للشاشة دي» | 🟡 الثقة مبنية على اختبار الباك-إند بس |
| **ميزة مؤجّلة بقرار** | «مفيش UI لإعادة الإرسال اليدوي — observability بس» | 🟢 قرار نطاق موثّق |
| **قيد حقيقي قايم** | بَقّة BullMQ #4479 · نقاط الولاء ماكانتش بتنتهي (اتقفلت) | 🔴 دي اللي تستاهل قرار |

**القاعدة**: الرقم الإجمالي مايقولش حاجة. الفئة هي اللي بتقول.

---

## 5. القاعدة الحاكمة لأي فجوة جديدة

عشان السجل ده يفضل مفيد:

1. الفجوة تتكتب بصيغة **«فجوة موثّقة صراحة: …»** طول ما هي مفتوحة.
2. أول ما تتقفل، الجملة تتغيّر لـ**«كانت فجوة موثّقة… اتقفلت بـ…»** — كلمة واحدة، والسجل بيتحدّث لوحده.
3. **ما تمسحش** الإشارة القديمة: تاريخ «إيه اللي كان ناقص وليه» أنفع من سطر نضيف.
